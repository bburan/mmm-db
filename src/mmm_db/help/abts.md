# Behavioural data

Go/no-go behavioural runs collected with psiexperiment, in the same
one-folder-per-run shape as the [physiology data](/help/mmm-db-cfts):

```
20250819-091648 Sean G011-1 modulation-gonogo
```

The folder name must end in the experiment name, and each run attaches to
an **animal event**.

## Experiment types

- **Modulation go/no-go**
- **Gap detection go/no-go**

## Preview buttons

| Button | What it shows |
|---|---|
| **Performance** | the session's performance PDF |
| **Settings** | the run's experiment settings as a table |
| **Threshold** | the fitted threshold for the session |
| **Video** | the session recording, played in the browser |

Behavioural runs do not report analysis status, so they never appear on
[Needs Analysis](/help/unrated-data) or the
[scoreboard](/help/analysis-scoreboard).
